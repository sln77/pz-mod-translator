Інструмент командного рядка для локалізації модів для **Project Zomboid (Build 42.15+)** за допомогою локального сервера `llama.cpp` (`llama-server`), що працює на основі **TranslateGemma**.

Він сканує Steam Workshop або локальні папки з модами на наявність файлів `Translate/EN/*.json`, оцінює обсяг перекладів (кількість рядків і символів), перекладає відсутні або оновлені рядки, і створює локальну копію кожного згенерованого перекладу, щоб ви могли легко створити самостійні модулі перекладів або відновити файли після оновлень Steam.

---

## Функції

- **Підтримка JSON у версії 42.15+:** Працює з сучасним форматом перекладів `.json`, який використовується в Project Zomboid B42.15+ (старі моди, що містять лише `.txt`-файли, безпечно пропускаються під час сканування).
- **Багатий термінальний інтерфейс:** Чисті кольорові таблиці, значки статусу та динамічні індикатори прогресу з відображенням минулого/залишеного часу за допомогою `rich`.
- **Многомовний CLI (`i18n`):** За замовчуванням використовує англійську мову та пропонує вибрати мову інтерфейсу з `cli_locales/*.json` під час інтерактивного запуску.
- **3 Режими роботи:**
  - **Режим 1:** Перекласти один конкретний мод (або його папку `Translate` / `EN`).
  - **Режим 2:** Скануйте всю директорію вашої майстерні, перевіряйте статус перекладу та обсяг символів для кожного модуля, і вибирайте модулі за номерами (`1,3,5`), діапазонами (`1-4`) або `всі`.
  - **Режим 3:** Управління збереженим прогресом — виявлення оновлень моду, переклад лише нових/змінених рядків, перезапис з початку, відновлення з дзеркала або чисте видалення згенерованих файлів.
- **Виявлення змін та відстеження прогресу:** Зберігає SHA-1 хеші для кожної ключа з початкових англійських рядків у файлі `pz_translator_state.json`. Якщо оновлення в Steam Workshop, лише нові або змінені англійські ключі додаються до черги для перекладу.
- **Локальний дзеркало (`pz_translator_mods/`):** Зберігає копію кожного перекладеного файлу, зберігаючи структуру відносних каталогів (що полегшує створення окремих модів, що містять лише переклади).
- **Безпечний та стійкий до збоїв:**
  - Існуючі переклади, які мають `0` невирішених ключів, ніколи не змінюються, перезаписуються або відстежуються.
  - Обробляє UTF-8 BOM, кома після останнього елемента в JSON-файлах, відредагованих вручну, та зберігає `$schema` та порожні рядки.
  - Автоматично зберігає прогрес періодично (`save_every`) та при натисканні `Ctrl+C`.

## Вимоги

- **Python 3.9+**
- **llama.cpp** (`llama-server`), що працює з моделлю **TranslateGemma** у форматі GGUF на налаштованому хості/порту (за замовчуванням: `http://127.0.0.1:8734`).
- Python залежності:

```bash
pip install -r requirements.txt
```

## Конфігурація (`config.json`)

При першому запуску (або через файл `config.json`, що додається) скрипт використовує наступні налаштування:

```json
{
    "llamacpp_host": "127.0.0.1",
    "llamacpp_port": 8734,
    "mods_path": "Z:\\steam\\steamapps\\workshop\\content\\108600",
    "default_source_lang": "EN",
    "default_target_lang": "RU",
    "ui_lang": "en",
    "mirror_dir": "pz_translator_mods",
    "state_file": "pz_translator_state.json",
    "save_every": 20
}
```

| Ключ | Опис |
| --- | --- |
| `llamacpp_host` | Адреса хоста вашого запущеного `llama-server` |
| `llamacpp_port` | Порт вашого запущеного `llama-server` |
| `mods_path` | Основний каталог, який сканується в режимі 2 (наприклад, папка Steam Workshop `108600`) |
| `default_source_lang` | Назва папки з вихідним перекладом (за замовчуванням: `EN`) |
| `default_target_lang` | За замовчуванням, код мови цілі (наприклад, `RU`, `DE`, `CN`, `JP`, `PTBR`) |
| `ui_lang` | Код мови інтерфейсу за замовчуванням з каталогу `cli_locales/` |
| `mirror_dir` | Місцевий каталог, де зберігаються повні шляхи до копій згенерованих перекладів. |
| `state_file` | Файл JSON, який зберігає історію перекладів та хеші вихідних рядків |
| `save_every` | Зберегти прогрес на диск та дублювати кожні N перекладених ключів |

## Використання

### Режим взаємодії

Спочатку запустіть `llama-server`, а потім виконайте:

```bash
python pz_translate.py
```

1. **Виберіть мову інтерфейсу:** Виберіть з доступних мов у `cli_locales/` (за замовчуванням: `en`).
2. **Вибір режиму:**
   - `1` — Перекласти конкретний шлях модуля.
   - `2` — Сканувати всі моди в `mods_path`, переглянути таблицю з кількістю рядків/символів, та ввести номери модів (наприклад, `1,3,5`, `1-4`, або `всі`).
   - `3` — Керування збереженим прогресом (оновлення змінених/нових ключів, повторний переклад з початку, відновлення з `pz_translator_mods/`, або видалення перекладів).
   - `4` — Змінити мову інтерфейсу.
   - `0` — Вихід.

### Аргументи командного рядка

Ви можете обійти інтерактивне меню, використовуючи прапори командного рядка (аргументи командного рядка перезаписують `config.json`):

| Прапор | Опис |
| --- | --- |
| `--config <шлях>` | Шлях до файлу `config.json` користувацького типу |
| `--mode {1, 2, 3}` | `1` = окремий мод, `2` = сканування директорії, `3` = керування збереженим прогресом |
| `--path <шлях>` | Шлях до папки з модами (Режим 1) або до кореневої папки з модами (Режим 2) |
| `--lang <code>` | Мова цілі як код папки PZ (`RU`, `CN`, `PTBR`) або ISO код (`ru`, `zh`, `pt-BR`) |
| `--source-lang <code>` | Перевизначення папки з вихідною мовою (за замовчуванням: `EN`) |
| `--host <хост>` | Перевизначення `llamacpp_host` |
| `--port <порт>` | Перевизначення `llamacpp_port` |
| `--ui-lang <code>` | Код мови інтерфейсу (наприклад, `en`, `ru`) |
| `--force` | Перезаписати вже існуючі переклади |

#### Приклади

```bash
# Translate a single mod to Russian
python pz_translate.py --mode 1 --path "Z:\steam\steamapps\workshop\content\108600\3268487204" --lang RU

# Force re-translation of a single mod to German
python pz_translate.py --mode 1 --path "Z:\steam\steamapps\workshop\content\108600\3268487204" --lang DE --force

# Scan all Workshop mods and pick mods interactively in Russian UI
python pz_translate.py --mode 2 --lang RU --ui-lang ru --port 8734

# Open the progress manager
python pz_translate.py --mode 3
```

## Як це працює

1. **Виявлення модів:** Рекурсивно шукає директорії `Translate/<SOURCE_LANG>`, які містять файли `.json`, і витягує назви модів з файлів `mod.info` та структури папок Workshop (`mods/<ModName>/<Version>`).
2. **Оцінка відмінностей та обсягу:** Порівнює ключі в `EN/*.json` з існуючими цільовими файлами (`<TARGET_LANG>/*.json`) та збереженими хешами SHA-1 у файлі `pz_translator_state.json`. Обробляються лише відсутні ключі або ключі, для яких текст англійського джерела змінився з моменту останнього перекладу.
3. **Переклад LLM:** Надсилає кожну рядок до `http://<хост>:<порт>/completion` за допомогою форматування діалогу TranslateGemma.
4. **Подвійний вивід:** Кожне ключове слово `save_every` (та при завершенні або натисканні `Ctrl+C`), записує дійсний JSON у форматі UTF-8 до:
   - Цей каталог, куди потрібно скопіювати модифікації: `...\Translate\<LANG>\<file>.json`
   - Локальна папка-зеркало: `pz_translator_mods\<повний_шлях_без_букви_диска>\Translate\<LANG>\<файл>.json`

## Примітки та обмеження

- **Підтримуваний формат:** Обробляються лише файли локалізації Project Zomboid **Build 42.15+** у форматі `.json`. Старі файли локалізації у форматі `.txt` ігноруються, оскільки B42.15+ більше не завантажує їх.
- **Мультиплеєр (`DoLuaChecksum`):** Оскільки папки `Translate` знаходяться всередині `media/lua/shared/`, додавання файлів перекладів безпосередньо всередині папок Steam Workshop може призвести до невідповідності контрольних сум на серверах мультиплеера з `DoLuaChecksum=true`. Для публічних серверів мультиплеера, або запакуйте віддзеркалені файли з `pz_translator_mods/` як окремий мод, призначений лише для перекладів, або грайте в одиночній грі / на серверах з `DoLuaChecksum=false`.
```
