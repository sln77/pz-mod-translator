# Перекладач моди для гри Project Zomboid

Інструмент командного рядка для локалізації модів для **Project Zomboid (версія 42.15+)** за допомогою локального сервера `llama.cpp` (`llama-server`), що працює на основі **TranslateGemma**.

Він сканує Steam Workshop або локальні папки з модами на наявність файлів `Translate/EN/*.json`, оцінює обсяг перекладів (кількість рядків і символів), перекладає відсутні або оновлені рядки, перевіряє змінні та теги UI, і створює локальну копію кожного згенерованого перекладу, щоб ви могли легко створити самостійні мовні моди або відновити файли після оновлень Steam.

---

## Особливості

- **Підтримка JSON версії 42.15+:** Працює з сучасним форматом `.json` для перекладів, який використовується в Project Zomboid B42.15+ (старі моди, що містять лише `.txt` файли, безпечно ігноруються під час сканування).
- **Багатий інтерфейс терміналу:** Чисті кольорові таблиці, значки статусу та динамічні індикатори прогресу з відображенням часу, що минув/залишився, за допомогою бібліотеки `rich`.
- **Многомовний інтерфейс командного рядка (`i18n`):** За замовчуванням використовує англійську мову, але під час інтерактивного запуску пропонує вибрати мову інтерфейсу з файлів `cli_locales/*.json`.
- **3 режими роботи:**
  - **Режим 1:** Перекласти окремий, вказаний модуль (або його папку `Translate` / `EN`).
  - **Режим 2:** Скануйте всю директорію вашої майстерні, перевіряйте статус перекладу та обсяг символів для кожного модуля, і вибирайте модулі за номерами (`1,3,5`), діапазонами (`1-4`), або за вказаним критерієм (`all`).
  - **Режим 3:** Управління збереженим прогресом — виявлення оновлень модуля, переклад нових/змінених/пошкоджених рядків, перезапис з початкових даних, відновлення з резервної копії, чисте видалення згенерованих файлів, або виконання звіту про перевірку токенів у тестовому режимі.
- **Визначення місця розташування та перевірка розмітки (`token_rules.json`):** Витягує місця розташування моду (`{name}`, `%1`) та теги RichText для Project Zomboid (`<LINE>`, `<RGB:...>`, `<IMAGE:...>`, тощо) за допомогою налаштованих правил регулярних виразів і перевіряє точну відповідність після перекладу. У разі невідповідності, повторює спроби з різними значеннями (`max_retries`). Якщо всі спроби не вдаються, зберігає оригінальний англійський текст, позначає статус моду як `EN/<LANG>`, і записує деталі в файл `pz_translator_issues.log`.
- **Виявлення оновлень та відстеження прогресу:** Зберігає SHA-1 хеші для кожного ключа з початкових англійських рядків у файлі `pz_translator_state.json`. Якщо оновлення в Steam Workshop, лише нові, змінені або пошкоджені ключі додаються до черги для перекладу.
- **Локальний дзеркало (`pz_translator_mods/`):** Зберігає копію кожного перекладеного файлу, зберігаючи структуру каталогів (що полегшує створення окремих модів, призначених лише для перекладу).
- **Безпечний та стійкий до збоїв:**
  - Існуючі переклади, виконані іншими авторами (як незмінені моди, так і окремі переклади, які не відстежуються у файлі `pz_translator_state.json`), ніколи не аналізуються на основі правил токенів, не змінюються та не перезаписуються.
  - Підтримує BOM UTF-8, кома після останнього елемента в JSON-файлах, відредагованих вручну, а також зберігає `$schema` та порожні рядки.
  - Автоматично зберігає прогрес періодично (`save_every`) та при натисканні клавіш `Ctrl+C`.

## Вимоги

- **Python 3.9 і новіші версії**
- **llama.cpp** (`llama-server`), який працює з моделлю **TranslateGemma** у форматі GGUF на налаштованому хості/порту (за замовчуванням: `http://127.0.0.1:8734`).
- Залежності Python:

```bash
pip install -r requirements.txt
```

## Конфігурація (`config.json`)

При першому запуску (або через файл `config.json`, що додається) скрипт використовує наступні налаштування:

```json
{
    "llamacpp_host": "127.0.0.1",
    "llamacpp_port": 8734,
    "mods_path": "Z:\\steam\\steamapps\\workshop\\content\\108600",
    "default_source_lang": "EN",
    "default_target_lang": "RU",
    "ui_lang": "en",
    "mirror_dir": "pz_translator_mods",
    "state_file": "pz_translator_state.json",
    "token_rules_file": "token_rules.json",
    "save_every": 20
}
```

| Ключові моменти | Опис |
| --- | --- |
| `llamacpp_host` | Адреса, за якою можна знайти ваш запущенний сервер `llama-server`. |
| `llamacpp_port` | Порт, який використовується вашим сервером `llama-server`. |
| `mods_path` | Основний каталог за замовчуванням, який сканується в режимі 2 (наприклад, папка `108600` у Steam Workshop). |
| `default_source_lang` | Назва папки з вихідним перекладом (за замовчуванням: `EN`) |
| `default_target_lang` | Стандартний код мови, який використовується за замовчуванням (наприклад, `RU`, `DE`, `CN`, `JP`, `PTBR`) |
| `ui_lang` | Стандартна мова інтерфейсу, вказана в `cli_locales/` |
| `mirror_dir` | Місцева папка, де зберігаються повні шляхи до копій згенерованих перекладів. |
| `state_file` | Файл JSON, який зберігає історію перекладів та хеші вихідних рядків. |
| `token_rules_file` | Файл JSON з правилами регулярних виразів та налаштуваннями для повторних спроб валідації замінників/тегів. |
| `save_every` | Зберегти прогрес на диск та копіювати кожні N перекладених ключів. |

### Валідація токенів (`token_rules.json`)

Правила регулярних виразів для захисту динамічних змінних та тегів розмітки в Project Zomboid зберігаються у файлі `token_rules.json`:

| Ключові моменти | Опис |
| --- | --- |
| `max_retries` | Максимальна кількість спроб перекладу з використанням різних початкових значень, коли ключові слова не збігаються. |
| `retry_temperatures` | Графік температур, що застосовується протягом усіх спроб повтору (наприклад, `[0.2, 0.35, 0.5]`) |
| `issues_log` | Файл журналу, де записуються рядки, які не пройшли перевірку після всіх спроб, разом із їхнім джерелом `EN` та інформацією про невдалі спроби. |
| `check_report` | Файл виводу для звіту про перевірку токенів у режимі 3 (без фактичного виконання). |
| `rules` | Масив об'єктів, що представляють правила регулярних виразів (`name`, `pattern`, `enabled`, `critical`, `description`) |

Правила, позначені `"critical": true`, викликають повторні спроби перекладу під час перекладу, а також відстежують ключі, які потребують повторного перекладу під час оновлень. Правила, що не є критичними (`"critical": false`), відображаються лише як попередження у звіті перевірки.

## Використання

### Режим взаємодії

Спочатку запустіть `llama-server`, а потім виконайте:

```bash
python pz_translate.py
```

1. **Виберіть мову інтерфейсу:** Виберіть з доступних мов у каталозі `cli_locales/` (за замовчуванням: `en`).
2. **Вибір режиму:**
   - `1` — Перекласти конкретний шлях модуля.
   - `2` — Просканувати всі модифікації у `mods_path`, переглянути таблицю з кількістю рядків/символів, та ввести номери модифікацій (наприклад, `1,3,5`, `1-4` або `all`).
   - `3` — Керування збереженим прогресом (оновлення нових/змінених/пошкоджених ключів, повторний переклад з початку, відновлення з папки `pz_translator_mods/`, видалення перекладів або запуск звіту про перевірку ключів без фактичного перекладу).
   - `4` — Змінити мову інтерфейсу.
   - `0` — Вихід.

### Аргументи командного рядка

Ви можете обійти інтерактивне меню, використовуючи параметри командного рядка (параметри командного рядка перекривають `config.json`):

| Прапор | Опис |
| --- | --- |
| `--config <path>` | Шлях до створення власного файлу `config.json` |
| `--rules <path>` | Шлях до створення власного файлу `token_rules.json` |
| `--mode {1,2,3}` | `1` = окремий режим, `2` = сканування директорії, `3` = керування збереженим прогресом |
| `--path <path>` | Шлях до папки з модами (Режим 1) або до кореневої папки з модами (Режим 2) |
| `--lang <code>` | Мова, для якої призначено папку PZ (код `RU`, `CN`, `PTBR`) або ISO код ( `ru`, `zh`, `pt-BR`) |
| `--source-lang <code>` | Перевизначити папку з вихідною мовою (за замовчуванням: `EN`) |
| `--host <host>` | Перевизначення `llamacpp_host` |
| `--port <port>` | Перевизначення `llamacpp_port` |
| `--ui-lang <code>` | Код мови інтерфейсу (наприклад, `en`, `ru`) |
| `--force` | Перезаписати існуючі переклади |
| `--check` | Проведіть перевірку токенів у всіх збережених перекладах і створіть файл `pz_translator_check_report.txt`. |

#### Приклади

```bash
# Translate a single mod to Russian
python pz_translate.py --mode 1 --path "Z:\steam\steamapps\workshop\content\108600\3268487204" --lang RU

# Force re-translation of a single mod to German
python pz_translate.py --mode 1 --path "Z:\steam\steamapps\workshop\content\108600\3268487204" --lang DE --force

# Scan all Workshop mods and pick mods interactively in Russian UI
python pz_translate.py --mode 2 --lang RU --ui-lang ru --port 8734

# Open the progress manager
python pz_translate.py --mode 3

# Run a dry-run token check on all saved translations without calling the LLM
python pz_translate.py --mode 3 --check
```

## Як це працює

1. **Виявлення модів:** Рекурсивно шукає директорії `Translate/<SOURCE_LANG>`, які містять файли `.json`, та витягує назви модів з файлів `mod.info` та структури папок Workshop (`mods/<ModName>/<Version>`).
2. **Порівняння та оцінка обсягу:** Порівнює ключі у файлах `EN/*.json` з існуючими цільовими файлами (`<TARGET_LANG>/*.json`), зберігає хеші SHA-1 у файлі `pz_translator_state.json` та важливі правила з файлу `token_rules.json`. Ключі, яких немає у цільових файлах, ключі, текст яких на англійській мові змінився, та відстежені ключі з пошкодженими замінниками/тегами, додаються до черги для перекладу; існуючі переклади авторів залишаються без змін.
3. **Переклад та перевірка LLM:** Надсилає кожну повну оригінальну послідовність до `http://<host>:<port>/completion` за допомогою стандартного формату запиту TranslateGemma, а потім перевіряє ключові слова на відповідність початковій послідовності. У разі невідповідності, повторює спроби з різними параметрами, до `max_retries`; якщо всі спроби не вдаються, зберігає оригінальний текст англійською мовою, позначає статус модифікації як `EN/<LANG>`, і записує деталі в `pz_translator_issues.log`.
4. **Подвійний вивід:** Кожна ключова фраза `save_every` (та також при завершенні або натисканні `Ctrl+C`) записує дійсний JSON у форматі UTF-8 до:
   - Цільова папка для модуля: `...\Translate\<LANG>\<file>.json`
   - Місцева папка зі дзеркальним копіюванням: `pz_translator_mods\<full_path_without_drive_letter>\Translate\<LANG>\<file>.json`

## Примітки та обмеження

- **Підтримувані формати:** Обробляються лише файли локалізації Project Zomboid **версії 42.15+** у форматі `.json`. Старі файли локалізації у форматі `.txt` ігноруються, оскільки версія 42.15+ більше не завантажує їх.
- **Мультиплеєр (`DoLuaChecksum`):** Оскільки папки `Translate` розташовані всередині `media/lua/shared/`, додавання файлів перекладу безпосередньо в папки Steam Workshop може призвести до невідповідності контрольних сум на серверах мультиплеєра з `DoLuaChecksum=true`. Для публічних серверів мультиплеєра, або запакуйте віддзеркалені файли з `pz_translator_mods/` як окремий мод лише для перекладу, або грайте в одиночному режимі / на серверах з `DoLuaChecksum=false`.
