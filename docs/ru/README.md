# Переводчик модов для игры Project Zomboid

Инструмент командной строки для локализации модов для игры **Project Zomboid (версия 42.15 и выше)**, использующий локальный сервер `llama.cpp` (`llama-server`), работающий на базе **TranslateGemma**.

Он сканирует Steam Workshop или локальные папки с модами в поисках файлов `Translate/EN/*.json`, оценивает объем перевода (количество строк и символов), переводит отсутствующие или обновленные строки, проверяет переменные и теги UI, и создает локальную копию каждого сгенерированного перевода, чтобы вы могли легко создавать самостоятельные моды с переводом или восстанавливать файлы после обновлений Steam.

---

## Особенности

- **Поддержка JSON в версии 42.15+:** Работает с современным форматом `.json`, используемым в Project Zomboid версии 42.15+ (старые моды, использующие только формат `.txt`, автоматически игнорируются во время сканирования).
- **Богатый интерфейс терминала:** Чистые таблицы с цветами, значки статуса и динамические индикаторы прогресса с отображением прошедшего и оставшегося времени, реализованные с помощью библиотеки `rich`.
- **Многоязычный интерфейс командной строки (`i18n`):** По умолчанию использует английский язык, и при интерактивном запуске предлагает выбрать язык интерфейса из файлов `cli_locales/*.json`.
- **3 режима работы:**
  - **Режим 1:** Перевести один конкретный мод (или его папку `Translate` / `EN`).
  - **Режим 2:** Просканируйте всю директорию вашей мастерской, проверьте статус перевода и объем символов для каждого модуля, и выберите модули по номерам (`1,3,5`), диапазонам (`1-4`), или по указанному вами критерию (`all`).
  - **Режим 3:** Управление сохраненным прогрессом — обнаружение обновлений мода, перевод новых/измененных/нерабочих строк, перезапись с нуля, восстановление из резервной копии, чистое удаление сгенерированных файлов или запуск отчета о проверке токенов в тестовом режиме.
- **Заполнители и проверка разметки (`token_rules.json`):** Извлекает заполнители мода (`{name}`, `%1`) и теги RichText для Project Zomboid (`<LINE>`, `<RGB:...>`, `<IMAGE:...>` и т.д.) с использованием настраиваемых правил регулярных выражений и проверяет точное соответствие после перевода. В случае несоответствия, повторяет попытки с разными значениями (`max_retries`). Если все попытки не увенчались успехом, сохраняет исходную английскую строку, отмечает статус мода как `EN/<LANG>`, и записывает детали в `pz_translator_issues.log`.
- **Обнаружение обновлений и отслеживание прогресса:** Хранит SHA-1 хэши исходных английских строк для каждого ключа в файле `pz_translator_state.json`. Если обновление в Steam Workshop вносит изменения, то только новые, измененные или с неверными ключами добавляются в очередь для перевода.
- **Локальный модуль (`pz_translator_mods/`):** Сохраняет копию каждого переведенного файла, сохраняя структуру каталогов (что упрощает создание отдельных модов, предназначенных только для перевода).
- **Безопасность и устойчивость к сбоям:**
  - Существующие переводы, выполненные другими авторами (как исходные модификации, так и отдельные переводы, не отслеживаемые в файле `pz_translator_state.json`), никогда не анализируются правилами токенизации, не изменяются и не заменяются.
  - Поддерживает BOM (бытовую строку) в формате UTF-8, завершающие запятые в JSON-файлах, отредактированных вручную, а также сохраняет `$schema` и пустые строки.
  - Автоматически сохраняет прогресс периодически (`save_every`) и при нажатии комбинации клавиш `Ctrl+C`.

## Требования

- **Python 3.9 и более поздние версии**
- **llama.cpp** (`llama-server`), работающий с моделью **TranslateGemma** в формате GGUF, на указанном хосте/порте (по умолчанию: `http://127.0.0.1:8734`).
- Зависимости Python:

```bash
pip install -r requirements.txt
```

## Настройка (`config.json`)

При первом запуске (или через файл `config.json`, который поставляется вместе со скриптом), скрипт использует следующие настройки:

```json
{
    "llamacpp_host": "127.0.0.1",
    "llamacpp_port": 8734,
    "mods_path": "Z:\\steam\\steamapps\\workshop\\content\\108600",
    "default_source_lang": "EN",
    "default_target_lang": "RU",
    "ui_lang": "en",
    "mirror_dir": "pz_translator_mods",
    "state_file": "pz_translator_state.json",
    "token_rules_file": "token_rules.json",
    "save_every": 20
}
```

| Ключевые моменты | Описание |
| --- | --- |
| `llamacpp_host` | Адрес хоста, на котором запущен ваш сервер `llama-server`. |
| `llamacpp_port` | Запуск сервера `llama-server` на вашем компьютере. |
| `mods_path` | По умолчанию, корневая директория сканируется в режиме 2 (например, папка `108600` в Steam Workshop). |
| `default_source_lang` | Имя папки с исходными переводами (по умолчанию: `EN`) |
| `default_target_lang` | Стандартный код языка по умолчанию (например, `RU`, `DE`, `CN`, `JP`, `PTBR`) |
| `ui_lang` | Стандартный код языка интерфейса из каталога `cli_locales/` |
| `mirror_dir` | Локальная папка, в которой хранятся полные пути к копиям сгенерированных переводов. |
| `state_file` | Файл JSON, содержащий историю переводов и хэши исходных строк. |
| `token_rules_file` | Файл JSON, содержащий правила регулярных выражений и настройки для повторных попыток при проверке заполнителей/тегов. |
| `save_every` | Сохраняйте прогресс на диске и создавайте резервные копии для каждой N-ой переведенной строки. |

### Проверка токенов (`token_rules.json`)

Правила регулярных выражений для защиты динамических переменных и тегов разметки в Project Zomboid, а также правила для `token_rules.json`:

| Ключевые моменты | Описание |
| --- | --- |
| `max_retries` | Максимальное количество попыток перевода с использованием различных начальных значений, когда ключевые слова не совпадают. |
| `retry_temperatures` | График температур, применяемый при повторных попытках (например, `[0.2, 0.35, 0.5]`) |
| `issues_log` | Файл журнала, в котором регистрируются строки, которые не прошли проверку после всех повторных попыток, вместе с указанием их источника `EN` и информацией о неудачных попытках. |
| `check_report` | Файл вывода для отчета о проверке токенов в режиме 3 (без фактического использования). |
| `rules` | Массив объектов, представляющих правила регулярных выражений (с полями `name`, `pattern`, `enabled`, `critical`, `description`) |

Правила, помеченные как `"critical": true`, вызывают повторные попытки при переводе, а также отслеживают ключи, которые необходимо перевести повторно при обновлениях. Правила, не являющиеся критическими (`"critical": false`), указываются только как предупреждения в отчете проверки "в тестовом режиме".

## Применение

### Режим взаимодействия

Сначала запустите `llama-server`, а затем выполните следующие команды:

```bash
python pz_translate.py
```

1. **Выберите язык интерфейса:** Выберите один из доступных языков в каталоге `cli_locales/` (по умолчанию: `en`).
2. **Режим выбора:**
   - `1` — Перевести конкретный путь мода.
   - `2` — Просканировать все моды в `mods_path`, просмотреть таблицу с количеством строк/символов, и ввести номера модов (например, `1,3,5`, `1-4` или `all`).
   - `3` — Управление сохраненным прогрессом (обновление ключей новых/измененных/недействительных токенов, повторное переведение с нуля, восстановление из папки `pz_translator_mods/`, удаление переводов или запуск отчета о проверке токенов без фактического перевода).
   - `4` — Изменить язык интерфейса.
   - `0` — Выход.

### Аргументы командной строки

Вы можете обойти интерактивное меню, используя флаги командной строки (флаги командной строки переопределяют `config.json`):

| Флаг | Описание |
| --- | --- |
| `--config <path>` | Путь к файлу `config.json` с пользовательской конфигурацией |
| `--rules <path>` | Путь к файлу `token_rules.json` с пользовательскими настройками. |
| `--mode {1,2,3}` | `1` = одиночный мод, `2` = сканирование директории, `3` = управление сохраненным прогрессом |
| `--path <path>` | Путь к папке модов (Режим 1) или к корневой папке модов (Режим 2) |
| `--lang <code>` | Язык, для которого предназначен данный файл (код папки PZ: `RU`, `CN`, `PTBR` или код ISO: `ru`, `zh`, `pt-BR`) |
| `--source-lang <code>` | Переопределить папку исходного языка (по умолчанию: `EN`) |
| `--host <host>` | Переопределить `llamacpp_host` |
| `--port <port>` | Переопределить `llamacpp_port` |
| `--ui-lang <code>` | Код языка интерфейса (например, `en`, `ru`) |
| `--force` | Переписать существующие переводы |
| `--check` | Проведите проверку токенов во всех сохранённых переводах и создайте файл `pz_translator_check_report.txt`. |

#### Примеры

```bash
# Translate a single mod to Russian
python pz_translate.py --mode 1 --path "Z:\steam\steamapps\workshop\content\108600\3268487204" --lang RU

# Force re-translation of a single mod to German
python pz_translate.py --mode 1 --path "Z:\steam\steamapps\workshop\content\108600\3268487204" --lang DE --force

# Scan all Workshop mods and pick mods interactively in Russian UI
python pz_translate.py --mode 2 --lang RU --ui-lang ru --port 8734

# Open the progress manager
python pz_translate.py --mode 3

# Run a dry-run token check on all saved translations without calling the LLM
python pz_translate.py --mode 3 --check
```

## Как это работает

1. **Поиск модов:** Рекурсивно ищет `Translate/<SOURCE_LANG>` директорий, содержащих `.json` файлов, и извлекает имена модов из структур папок `mod.info` и Workshop (`mods/<ModName>/<Version>`).
2. **Сравнение и оценка объема:** Сравнивает ключи в файлах `EN/*.json` с существующими целевыми файлами (`<TARGET_LANG>/*.json`), а также с хешами SHA-1, хранящимися в файле `pz_translator_state.json`, и критическими правилами из файла `token_rules.json`. Ключи, которых нет, ключи, для которых исходный текст на английском языке был изменен, и отслеживаемые ключи с нерабочими плейсхолдерами/тегами, помечены для перевода; существующие переводы авторов остаются без изменений.
3. **Перевод и проверка с использованием LLM:** Отправляет каждое полное исходное предложение в `http://<host>:<port>/completion` с использованием стандартного формата запроса TranslateGemma, а затем проверяет ключевые слова на соответствие исходному предложению. В случае несоответствия, повторяет попытки с разными начальными значениями до `max_retries`; если все попытки не увенчались успехом, сохраняет исходный текст на английском языке, отмечает статус изменения как `EN/<LANG>`, и записывает детали в `pz_translator_issues.log`.
4. **Двойной вывод:** Каждое значение ключа `save_every` (а также при завершении работы или нажатии `Ctrl+C`) записывает корректный JSON в формате UTF-8 в:
   - Целевая папка для мода: `...\Translate\<LANG>\<file>.json`
   - Локальная папка со зеркалами: `pz_translator_mods\<full_path_without_drive_letter>\Translate\<LANG>\<file>.json`

## Примечания и ограничения

- **Поддерживаемые форматы:** Обрабатываются только файлы локализации Project Zomboid в формате `.json` версии **42.15+**. Старые файлы локализации в формате `.txt` игнорируются, так как версия 42.15+ больше не загружает их.
- **Многопользовательский режим (`DoLuaChecksum`):** Поскольку папки `Translate` находятся внутри папки `media/lua/shared/`, добавление файлов перевода непосредственно в папки Steam Workshop может привести к несоответствию контрольных сумм на многопользовательских серверах с `DoLuaChecksum=true`. Для публичных многопользовательских серверов, либо упакуйте зеркальные файлы из `pz_translator_mods/` в отдельный мод, предназначенный только для перевода, либо играйте в одиночном режиме / на серверах с `DoLuaChecksum=false`.
