Инструмент командной строки для локализации модов для **Project Zomboid (версия 42.15 и выше)** с использованием локального сервера `llama.cpp` (`llama-server`), работающего на базе **TranslateGemma**.

Он сканирует Steam Workshop или локальные папки с модами в поисках файлов `Translate/EN/*.json`, оценивает объем перевода (количество строк и символов), переводит отсутствующие или обновленные строки, и создает локальные копии всех сгенерированных переводов, чтобы вы могли легко упаковывать самостоятельные моды с переводом или восстанавливать файлы после обновлений Steam.

---

## Функции

- **Поддержка JSON в версии 42.15+:** Работает с современным форматом перевода `.json`, используемым в Project Zomboid B42.15+ (старые моды, использующие только `.txt`, безопасно игнорируются во время сканирования).
- **Богатый интерфейс терминала:** Чистые цветные таблицы, значки статуса и динамические индикаторы прогресса с отображением прошедшего/оставшегося времени, используя библиотеку `rich`.
- **Многоязычный CLI (`i18n`):** По умолчанию использует английский язык и предлагает выбрать язык интерфейса из `cli_locales/*.json` при интерактивном запуске.
- **3 Режима работы:**
  - **Режим 1:** Перевести один конкретный мод (или его папку `Translate` / `EN`).
  - **Режим 2:** Сканируйте всю директорию вашей мастерской, проверьте статус перевода и объем символов для каждого мода, и выберите моды по номерам (`1,3,5`), диапазонам (`1-4`) или `все`.
  - **Режим 3:** Управление сохраненным прогрессом — обнаружение обновлений мода, перевод только новых/измененных строк, перезапись с нуля, восстановление из зеркала или чистое удаление сгенерированных файлов.
- **Обнаружение обновлений и отслеживание прогресса:** Хранит SHA-1 хэши исходных английских строк для каждого ключа в файле `pz_translator_state.json`. Если обновление устанавливается через Steam Workshop, только новые или измененные английские ключи добавляются в очередь для перевода.
- **Локальный реплика (`pz_translator_mods/`):** Сохраняет копию каждого переведенного файла, сохраняя структуру каталогов (что упрощает создание автономных модов, содержащих только переводы).
- **Безопасность и отказоустойчивость:**
  - Существующие переводы, у которых нет никаких ожидающих обработки ключей (с значением `0`), никогда не изменяются, не перезаписываются и не отслеживаются.
  - Обрабатывает BOM UTF-8, завершающие запятые в JSON-файлах модов, отредактированных вручную, и сохраняет `$schema` и пустые строки.
  - Автоматически сохраняет прогресс периодически (`save_every`) и при нажатии `Ctrl+C`.

## Требования

- **Python 3.9+**
- **llama.cpp** (`llama-server`), работающий с моделью **TranslateGemma** в формате GGUF на указанном хосте/порту (по умолчанию: `http://127.0.0.1:8734`).
- Зависимости Python:

```bash
pip install -r requirements.txt
```

## Конфигурация (`config.json`)

При первом запуске (или через файл `config.json`, который поставляется вместе со скриптом), скрипт использует следующие настройки:

```json
{
    "llamacpp_host": "127.0.0.1",
    "llamacpp_port": 8734,
    "mods_path": "Z:\\steam\\steamapps\\workshop\\content\\108600",
    "default_source_lang": "EN",
    "default_target_lang": "RU",
    "ui_lang": "en",
    "mirror_dir": "pz_translator_mods",
    "state_file": "pz_translator_state.json",
    "save_every": 20
}
```

| Ключ | Описание |
| --- | --- |
| `llamacpp_host` | Адрес хоста, на котором запущен `llama-server` |
| `llamacpp_port` | Порт, на котором работает ваш `llama-server` |
| `mods_path` | По умолчанию, сканируется корневая директория, находящаяся в режиме 2 (например, папка `108600` в Steam Workshop). |
| `default_source_lang` | Имя папки с исходными переводами (по умолчанию: `EN`) |
| `default_target_lang` | Стандартный код языка-цели (например, `RU`, `DE`, `CN`, `JP`, `PTBR`) |
| `ui_lang` | Код языка интерфейса по умолчанию из каталога `cli_locales/` |
| `mirror_dir` | Локальная папка, где хранятся полные пути к копиям сгенерированных переводов. |
| `state_file` | Файл JSON, содержащий историю переводов и хэши исходных строк |
| `save_every` | Сохраняйте прогресс на диск и создавайте резервные копии каждого N переведенного ключа. |

## Использование

### Режим интерактивного управления

Сначала запустите `llama-server`, а затем выполните:

```bash
python pz_translate.py
```

1. **Выбрать язык интерфейса:** Выберите язык из доступных в `cli_locales/` (по умолчанию: `en`).
2. **Выбор режима:**
   - `1` — Перевести конкретный путь мода.
   - `2` — Сканировать все моды в `mods_path`, просмотреть таблицу со количеством строк/символов, и ввести номера модов (например, `1,3,5`, `1-4` или `all`).
   - `3` — Управление сохраненным прогрессом (обновление измененных/новых ключей, повторный перевод с нуля, восстановление из `pz_translator_mods/`, или удаление переводов).
   - `4` — Изменить язык интерфейса.
   - `0` — Выход.

### Аргументы командной строки

Вы можете обойти интерактивное меню, используя флаги командной строки (аргументы командной строки переопределяют `config.json`):

| Флаг | Описание |
| --- | --- |
| `--config <путь>` | Путь к пользовательскому файлу `config.json` |
| `--mode {1, 2, 3}` | `1` = одиночный мод, `2` = сканирование директории, `3` = управление сохраненным прогрессом |
| `--path <путь>` | Путь к папке мода (Режим 1) или к корневой папке модов (Режим 2) |
| `--lang <code>` | Язык, на который нужно перевести, в виде кода папки PZ (`RU`, `CN`, `PTBR`) или ISO-кода (`ru`, `zh`, `pt-BR`) |
| `--source-lang <code>` | Переопределить папку исходного языка (по умолчанию: `EN`) |
| `--host <хост>` | Переопределить `llamacpp_host` |
| `--port <порт>` | Переопределить `llamacpp_port` |
| `--ui-lang <code>` | Код языка интерфейса (например, `en`, `ru`) |
| `--force` | Перезаписать существующие переводы |

#### Примеры

```bash
# Translate a single mod to Russian
python pz_translate.py --mode 1 --path "Z:\steam\steamapps\workshop\content\108600\3268487204" --lang RU

# Force re-translation of a single mod to German
python pz_translate.py --mode 1 --path "Z:\steam\steamapps\workshop\content\108600\3268487204" --lang DE --force

# Scan all Workshop mods and pick mods interactively in Russian UI
python pz_translate.py --mode 2 --lang RU --ui-lang ru --port 8734

# Open the progress manager
python pz_translate.py --mode 3
```

## Как это работает

1. **Обнаружение модов:** Рекурсивно ищет каталоги вида `Translate/<SOURCE_LANG>`, содержащие файлы с расширением `.json`, и извлекает имена модов из файлов `mod.info` и структуры папок Workshop (`mods/<ModName>/<Version>`).
2. **Оценка различий и объема:** Сравнивает ключи в `EN/*.json` с существующими целевыми файлами (`<TARGET_LANG>/*.json`) и сохраненными хэшами SHA-1 в `pz_translator_state.json`. Очередь формируется только для отсутствующих ключей или ключей, для которых текст на английском языке был изменен с момента последнего перевода.
3. **Перевод с помощью LLM:** Отправляет каждую строку по адресу `http://<host>:<port>/completion`, используя формат чата TranslateGemma.
4. **Двойной вывод:** Каждое значение ключа `save_every` (а также при завершении или нажатии `Ctrl+C`) записывает корректный JSON в формате UTF-8 в:
   - Целевая папка для мода: `...\Translate\<LANG>\<file>.json`
   - Локальная папка-зеркало: `pz_translator_mods\<полный_путь_без_буквы_диска>\Translate\<ЯЗЫК>\<файл>.json`

## Примечания и ограничения

- **Поддерживаемый формат:** Обрабатываются только файлы локализации Project Zomboid в формате `.json` версии **Build 42.15+**. Старые файлы локализации в формате `.txt` игнорируются, так как B42.15+ больше не загружает их.
- **Многопользовательский режим (`DoLuaChecksum`):** Поскольку папки `Translate` находятся внутри `media/lua/shared/`, добавление файлов перевода непосредственно в папки Steam Workshop может привести к несоответствию контрольных сумм на многопользовательских серверах с `DoLuaChecksum=true`. Для публичных многопользовательских серверов, либо упакуйте зеркальные файлы из `pz_translator_mods/` в отдельный мод, содержащий только файлы перевода, либо играйте в одиночном режиме / на серверах с `DoLuaChecksum=false`.
```
